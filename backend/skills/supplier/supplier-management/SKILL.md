# 供应商管理能力

## 适用范围

- **供应商查询**：根据用户输入的名称关键词搜索供应商。
- **创建供应商**：收集供应商数据、校验数据，组装创建请求报文，并提交审批。

审批流程以及Motorparts系统数据持久化属于外部能力。本能力仅定义数据收集、数据校验、请求报文组装以及面向用户的状态展示规则。

## 查询流程

1. 从请求中提取供应商名称关键词。若无可用关键词，向用户确认补充信息。
2. 调用 `search_suppliers(name=...)`，如实返回查询得到的数据。
3. 查询为只读操作，禁止调用 `create_supplier`，也不可触发审批流程。

## 创建流程

### 1. 生成草稿

将用户提供的数据提取至`supplier_draft`（供应商草稿）。**禁止自行编造**供应商编码、联系人信息、信用评级或业务默认值。

### 2. 校验数据并索要缺失信息

依据下述必填字段规则对草稿进行校验。

1. 识别所有缺失或校验不通过的必填阻断字段。
2. 若存在阻断字段，调用`request_supplier_info`，入参包含：
   - `supplier_draft`：当前的供应商草稿；
   - `missing_fields`：仅填写校验失败的阻断字段名称；
   - `message`：一条中文业务友好提示，向用户索要全部所需信息，不要暴露内部字段名。
3. `missing_fields`列表不能为空时，才可调用`request_supplier_info`。
4. 获取到用户返回内容`human_response`后，将新信息合并至现有草稿，保留原有未修改内容，再次执行校验。

### 3. 组装请求报文，提交审批

所有阻断字段校验通过后：

1. 剔除值为`null`或者空字符串的数据。
2. `supplier_payload`（供应商请求报文）中仅允许包含许可的创建字段。
3. 调用`create_supplier(supplier_payload=...)`，进入审批流程。

审批未完成、Motorparts未返回成功结果前，仅告知用户供应商信息已提交审批。**禁止告知用户供应商已创建、已保存或已写入Motorparts系统**。

## 必填字段规则

| 业务信息 | 字段 | 校验规则 | 校验失败处理 |
| --- | --- | --- | --- |
| 供应商编码 | `supplierCode` | 用户输入非空文本 | 阻断流程，向用户索要 |
| 供应商名称 | `name` | 用户输入非空文本 | 阻断流程，向用户索要 |
| 联系人 | `contactPerson` | 非空文本 | 阻断流程，向用户索要 |
| 联系电话 | `phone` | 非空文本 | 阻断流程，向用户索要 |
| 邮箱 | `email` | 非空邮箱地址，必须包含`@`符号，且`@`前后均有内容 | 阻断流程，向用户索要 |
| 地址 | `address` | 非空文本 | 阻断流程，向用户索要 |
| 信用评级 | `creditRating` | 非空文本 | 阻断流程，向用户索要 |

不得私自修正用户输入的内容与格式，需要求用户自行修改无效数据。

## 请求报文约定

`supplier_payload`中仅可包含以下字段：

```json
{
  "supplierCode": "SUP001",
  "name": "示例零部件有限公司",
  "contactPerson": "张三",
  "phone": "13800138000",
  "email": "zhangsan@example.com",
  "address": "上海市 示例区",
  "creditRating": "A"
}
```

禁止携带`id`、`createTime`、`updateTime`、`deleted`、`status`字段，以上字段由Motorparts系统维护或自动赋值。
本能力不校验供应商编码唯一性，该校验由下游Motorparts系统完成。

## 用户取消操作与外部返回结果

- 用户明确取消操作时，丢弃`supplier_draft`草稿，结束流程。
- 审批被驳回时，告知用户该申请已被驳回，保留草稿，支持用户修改后重新提交。
- Motorparts系统报错时，如实反馈返回的错误信息，不得告知用户操作成功。
- 只有审批接口返回成功，才可以确认供应商创建完成。
